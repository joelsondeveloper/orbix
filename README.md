# orbix

🟣 ORBIX
Sua rotina. Seu ritmo. Sua inteligência.

Orbix é uma aplicação de produtividade que cria hábitos e rotinas dinamicamente usando inteligência artificial.
Aqui você não “só cria tarefas”. Aqui você constrói uma vida organizada com o mínimo de atrito.

🚀 Features (roadmap inicial)

IA que cria rotinas inteligentes com base no dia do usuário.

Gatilhos, metas e blocos dinâmicos.

Ajustes inteligentes conforme comportamento.

Sistema modular de gamificação: 0 a 10 (Notion → RPG com chefões).

Modo privado (sem banco + localStorage/IndexedDB).

Modo nuvem com criptografia.

Layout futurista inspirado em Orbit/Space vibes.

🧩 Stack

React + Vite

TypeScript

TailwindCSS

Zustand ou Context API

Node/Express (futuro)

LLM/IA helpers (a definir)

📦 Como rodar
npm install
npm run dev

🛠 Futuro do projeto

Integração com API própria de IA.

Modo offline-first.

Gamificação avançada estilo “missões + tier list”.
